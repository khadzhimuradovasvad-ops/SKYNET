# SKYNET 1.1.0 — Security and Disclosure Boundary

## Publication Principle
**Publish observable system properties and experimental evidence without publishing sufficient information to reconstruct the private mechanism.**

## Public Record
The public record includes finalized version identity, source metrics and cryptographic hash, validation totals, runtime experiment results, observable autonomous behavior, high-level capability descriptions, research position, and public changelog.

## Private Technology
SKYNET source code, internal connection maps, reconstruction-level architecture, private mathematical implementation details, internal parameters and thresholds, implementation-specific control sequences, private validators, private validation infrastructure, technical archives, and protected working materials remain private.

## Determinator Boundary

This repository is a public technical record, not a source distribution channel.
